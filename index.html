Este portfólio reúne os exercícios e protótipos desenvolvidos durante o curso de Desenvolvimento Web.

Os projetos demonstram o uso de marcação semântica, estilização com CSS, interatividade com JavaScript, formulários, layouts responsivos e boas práticas de organização de código.
