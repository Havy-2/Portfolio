# Portfólio — Desenvolvimento Web

Portfólio acadêmico com os projetos do curso de Desenvolvimento Web.

## Como abrir

Abra o arquivo `index.html` no navegador.

## Projetos incluídos

| Projeto | Pasta | Descrição |
|---------|-------|-----------|
| Mirror Fashion | `../exercicios/exercicio1-mirrorfashion/` | Site de moda (Caelum) |
| Focinho Feliz | `../exercicios/exercicio3-focinhofeliz/` | Pet shop fictício |
| Coop Livraria Cuca Legal | `../exercicios/exercicio4-livraria-cuca-legal/` | Livraria cooperativa (principal) |

## Personalização

Antes de entregar para a professora, edite o arquivo `index.html` e substitua:

- `[Seu Nome]` pelo seu nome completo
- Os dados de contato na seção final

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie o conteúdo da pasta `portfolio` para a raiz do repositório.
3. Vá em **Settings → Pages** e escolha a branch `main` / pasta raiz.
4. O site ficará disponível em `https://seu-usuario.github.io/nome-do-repositorio/`
